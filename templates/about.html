About this system

University DBMS project — Indian Vehicle Import Eligibility & Carnet Management

Purpose

This system demonstrates how a relational database — not application code — can be the authoritative decision engine for a compliance workflow. A MySQL stored procedure evaluates every active rule and records a pass or fail per rule. Flask renders the output; no eligibility logic lives in Python.

The primary subject is the Carnet de Passages en Douane (CPD), an international customs document that lets a vehicle be temporarily imported without paying full import duties, recognised in over 100 AIT/FIA member countries including India.

Disclaimer. This is an educational project. Always verify requirements with official Indian authorities (DGFT, Customs, Ministry of Road Transport) before any real import.

Technology stack

Database
  • MySQL 8.0 · InnoDB
  • 14 tables in 3NF
  • Stored function + procedure
  • 5 triggers · 5 views
Application
  • Python 3.11 · Flask
  • mysql-connector-python
  • Bootstrap 5 · IBM Plex Sans
  • Werkzeug password hashing
