About This Project

Project Overview

The Indian Vehicle Import Eligibility & Carnet Management System is a university DBMS project demonstrating advanced MySQL features. The database — not the Python code — makes all eligibility decisions through a stored procedure, triggers, and views.

It covers:

  • Carnet de Passages en Douane management
  • Rule-based eligibility checking (vehicle age, fuel type, steering side, engine CC, carnet validity, document submission)
  • Full audit trail via triggers
  • Admin CRUD interface with role-based access

Carnet de Passages en Douane

A Carnet de Passages en Douane (CPD) is an international customs document that allows a vehicle to be temporarily imported into a country without paying full import duties. It is issued by national automobile clubs and is recognised in over 100 countries that are members of the Alliance Internationale de Tourisme (AIT) or the Fédération Internationale de l'Automobile (FIA).

For temporary import into India, a valid CPD is mandatory. This system tracks CPD numbers, issuing countries, validity dates, and automatically sets the status to EXPIRED via a database trigger when the expiry date passes.

Disclaimer: This is an educational project only. The rules, fees, and procedures for vehicle import into India are subject to change. Always verify current requirements with official Indian authorities (DGFT, Customs, Ministry of Road Transport) before making any real import decision.
